# Kompass

Habits, Ziele, Aufgaben und Journal in einer App, dazu ein Assistent als Berater. Kompass liest deine Kalender (Apple, Google über das iPhone) und sagt dir, wann was passt – Termine legst du in deinem Kalender an.

- **Für den Gründer:** `docs/produkt/roter-faden/kompass-roter-faden.docx` – die App Seite für Seite
- **Stand und nächste Schritte:** `docs/stand.md`
- **Aufgaben:** `/fahrplan` in Claude Code
- **App:** `Kompass.xcodeproj` (SwiftUI), Aufbau in `docs/technik/app.md`
- Wegweiser zu allen Dokumenten: `docs/README.md`
